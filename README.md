# kavyaagrawal-02.github.io

Academic website of Kavya Agrawal, PhD scholar, TERI School of Advanced Studies, New Delhi.
Live at https://kavyaagrawal-02.github.io

- Pages: `index.html`, `research.html`, `publications.html`, `teaching.html`, `cv.html`, plus `Kavya_Agrawal_CV.pdf`.
- Content lives in `_build/build.py`; run `python3 _build/build.py` to rebuild the pages.
- Styles: `assets/site.css`. Images: `assets/img/`. Font: Newsreader (SIL Open Font License, `assets/fonts/OFL.txt`).
