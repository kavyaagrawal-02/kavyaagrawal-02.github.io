# kavyaagrawal-02.github.io

Academic website of Kavya Agrawal, PhD scholar, TERI School of Advanced Studies, New Delhi.
Live at https://kavyaagrawal-02.github.io

- Pages are plain HTML (`index.html`, `research.html`, `publications.html`, …).
- To add a paper: open `publications.html`, copy one `<li class="entry">…</li>` block and edit it.
- Styles: `assets/style.css`. Photos and figures: `assets/img/`.
